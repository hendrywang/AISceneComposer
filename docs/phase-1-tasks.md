## 目标:跑通一个垂直切片

阶段 1 只做 **Web(桌面浏览器 + iPad Safari)**,原生打包延后(D15)。目标是端到端跑通一遍闭环:

> 摆资产 → 转相机 → 导出干净截图 → 调 Nano Banana 2 → 出图 → 登录并保存。

不追求功能完整,追求**整条链路能用**。完成即证明产品成立,可进入阶段 2 铺量。

## M1.0 骨架与渲染

- [ ] **T1 — 项目骨架 + Three.js 画布**
  - 按 [project-structure.md](./project-structure.md) 建 monorepo(pnpm + Turborepo),`apps/client` 起 Expo web,渲染一个立方体。
  - **按需渲染**:仅在交互(相机移动/选中/变更)时重绘,不跑常驻渲染循环。
  - 验收:桌面浏览器与 **iPad Safari** 都能显示立方体并转视角;静止时 GPU 占用接近 0。
- [ ] **T2 — 视角控制 + 触摸点选**
  - OrbitControls(轨道/平移/缩放)+ 射线点选物体并高亮。
  - **重点:解决 raycaster 与 OrbitControls 的触摸事件冲突**(见 project-structure Gotchas),保证 iPad 上能点中物体。
  - 验收:桌面(鼠标)与 iPad(触摸)都能旋转视角并点选/取消选中物体。

## M1.1 资产与摆放

- [ ] **T3 — glTF 加载 + 资产库面板**
  - `GLTFLoader + DRACOLoader` 加载 [asset-library.md](./asset-library.md) 的起步资产(5–10 个);左侧库面板列缩略图。
  - 卸载/删除物体时调用 `geometry/material/texture.dispose()` 释放显存。
  - 验收:点缩略图把资产加入场景;反复加删 30 分钟显存不持续上涨。
- [ ] **T4 — 摆放交互**
  - 拖入、移动(吸附地面)、绕 Y 轴旋转、删除;选中显示 gizmo;每个角色挑选预设姿势(`poseId`)与身份色(`idColor`)。
  - 验收:能在一个房间里摆出"一人站、一人坐"的双人场景。

## M1.2 相机 / 镜头系统(产品核心)

- [ ] **T5 — 多相机数据与切换**
  - 实现 `Scene.cameras[]`:新建、命名、切换 `activeCameraId`、调 FOV。
  - 验收:同一布景存 ≥3 个机位并自由切换;切换即时生效。
- [ ] **T6 — 电影镜头预设**
  - 预设:过肩(OTS)、双人镜、仰拍、俯拍、特写;**基于选中角色实时计算机位/朝向**(不存死坐标)。
  - 验收:选中角色后点任一预设,相机自动就位;换了角色摆位再点仍正确。

## M1.3 导出与生成

- [ ] **T7 — 渲染模式 + 截图导出**
  - 导出时切"渲染模式":隐藏网格/gizmo/高亮,角色切身份纯色(风格按 T13 锁定);离屏渲染固定尺寸,`canvas.toBlob` 出 **WebP**。
  - 验收:导出的截图干净无辅助元素,尺寸固定,体积合理(WebP)。
- [ ] **T8 — 后端生成服务(Cloud Run / Node)**
  - `services/api`:`POST /generate` 接收 `GenerateRequest`(截图 + prompt + style)→ 调 Gemini 图像(Nano Banana 2)→ 返回成图。先做同步,后续可换异步队列(见性能小节)。
  - 验收:本地起服务,用一张截图 + prompt 调用,几秒内返回一张 AI 图。
- [ ] **T9 — 前端生成流程**
  - 写实/二次元 `style` 切换 + prompt 输入框 + "生成"按钮;乐观 UI + 进度态 + 结果展示与保存。
  - 验收:编辑器里点"生成",几秒后看到忠实于布景与机位的 AI 图。

## 横切关注点(贯穿所有任务)

- **按需渲染**:编辑器默认不重绘,仅事件驱动(省电、iPad 友好)。
- **显存管理**:任何移除操作都 `dispose()` 几何/材质/纹理。
- **devicePixelRatio / 画布尺寸**:画布按 `逻辑尺寸 × dpr` 设置,CSS 缩回逻辑尺寸,保证触摸坐标→射线正确。
- **真机验证**:iOS 模拟器的 GLView 会崩,**必须用真机 iPad** 验证触摸与显存。

## 阶段 1 完成定义(DoD)

1. 桌面 + iPad Safari 上,能从空场景摆出双人室内景、设多机位、一键出图。
2. 登录后场景与成图持久化,跨会话恢复,数据按用户隔离。
3. 写实/二次元两套配方可用,出图忠实于布景与机位。
4. 不违反:D4(无 IK,只用固定姿势)、D5(暂不做角色一致性)、D15(仅 Web 目标)。
